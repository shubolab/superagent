# 压缩前模型输入计量

## Why

上下文压缩需要在派发前准确判断模型窗口，并确认计量的输入就是发送的输入。先用可控适配器验收计量契约。

## What Changes

- 经本地 Mesh 查询所选模型绑定的窗口、计量结果和输入指纹。
- 执行窗口、保留输出、安全余量及 SDK 输入字节的硬边界。
- 当实测低估超过校准余量时停用对应模型计量版本，重新装配后可用新校准恢复。

## Capabilities

### New Capabilities

- `context-input-metering` 定义模型计量、输入指纹和派发准入。

## Impact

新增可选的 SDK 模型计量接口与运行器策略。摘要、候选视图和真实供应商压缩启用在后续切片。
