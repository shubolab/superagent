# 模型输入计量设计

## Context

[上下文压缩契约](../../../docs/specs/context-compaction-contract.md#计量与发送) 要求适配器在同一编码路径计量并检查发送指纹。

## Goals / Non-Goals

建立可验证的本地计量及硬额度裁决。提供方只有经过宿主校准才可声明可用估算。完整压缩及真实供应商启用另行验证。

## Decisions

| 职责 | 实现 |
| --- | --- |
| 宿主 | 对指定模型配置输出保留、安全余量和已校准的估算版本。默认关闭 |
| 适配器 | 用模型、计量版本和供应商实际输入编码生成指纹。发送前重新编码核对指纹 |
| Mesh | 经原绑定路由计量请求和实测超差报告。失效状态在同一装配、模型和计量版本内共享 |
| 运行器 | 检查硬窗口及累计字节额度，携带指纹派发，处理缺计量、请求变化和供应商窗口错误 |

## Risks / Trade-offs

计量可选并沿用本地接口。缺少实测校准时适配器可继续服务普通 Run，压缩路径保持关闭。
