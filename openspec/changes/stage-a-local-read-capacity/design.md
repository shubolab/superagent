# 本地有界读取容量设计

## Context

[执行环境声明](../../../docs/specs/execution-environment.md#资源声明和执行) 与 [大文件搜索验收](../../../docs/specs/run-budget.md#大文件搜索验收) 规定实际额度和并发边界。

## Goals / Non-Goals

对进程内、经许可的本地读取执行并发及等待上限。通用命令和跨节点调度遵循各自的后续设计。

## Decisions

- 容量归同一环境实例，所有工作区共享。默认 8 个活跃位置和 16 个等待位置，宿主可配置，等待位置可为零。
- 等待发生在签发许可前，使用 Run 截止。只有许可持有者才进入 Tool.Invoke。
- 在许可成功撤销或随 Run 回收后释放活跃位置。排队取消归还等待位置。超额拒绝走现有可配对工具结果。
- 内置实现公布每次扫描硬上限。原有第三方环境接口继续可用，可以增量提供能力声明。

## Risks / Trade-offs

A 的容量限制保证界限和取消，不附带跨 Run 公平调度承诺。
