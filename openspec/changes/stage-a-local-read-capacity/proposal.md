# 阶段 A · 本地读取容量

## Why

单次搜索的扫描和缓冲已有上限。多个 Run 共用环境时，活跃读取和等待同样需要硬上限。

## What Changes

- 本地环境公布能强制兑现的读字节额度、截止时间、并发和排队上限。
- 运行器取环境公告、工具限额和 Run 余量的交集，在签发按次授权时取得容量。
- 队列满回报可识别的派发前拒绝，排队取消和释放归还容量。

## Capabilities

### New Capabilities

- `local-read-capacity` 定义本地读取能力与共享容量边界。

## Impact

增加本地环境配置入口、Mesh 能力查询和并发验收。现有构造器采用有限默认值。
