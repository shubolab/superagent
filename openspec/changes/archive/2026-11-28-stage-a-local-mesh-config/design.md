# 本地 Mesh 文件装配设计

## Context

[Mesh 本地配置格式](../../../docs/specs/mesh-transport.md#本地配置格式) 已规定 YAML 形状和拒绝条件。

## Goals / Non-Goals

支持声明版本、组件映射、运行器可见列表和默认环境。凭据、主体解析、预算、授权和组件生命周期由 Go 宿主持有。

## Decisions

- `LoadMeshConfig` 接收读流和宿主实现登记表，产出同一 `MeshConfig`。运行器引用对应宿主提供的运行器策略。
- 文件的组件引用用于缩小可见范围。发现宿主策略超出文件范围时装配失败。
- 默认环境补全已有工作区要求中的环境引用，明确输入的环境继续按原值判断。

## Risks / Trade-offs

单个文件只接受一个文档。文件有界，解析后统一进入现有绑定校验。
