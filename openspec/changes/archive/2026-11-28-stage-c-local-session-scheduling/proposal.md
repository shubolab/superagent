# 阶段 C · 本地会话调度

## Why

会话历史已能独立提交。两个会话共用一个 Run 名额时，宿主仍需要一处统一裁决容量、等待顺序和名额交接。

## What Changes

- 宿主为本地逻辑运行器启用调度，配置活跃 Run 上限、等待数和最长等待时间。
- 名额满时按入队顺序等待。等待可取消或到期，队列满时立即拒绝新请求。
- 名额从受理开始占用，到运行器确认终止或明确未受理时释放。释放后自动推进下一条有效请求。

## Capabilities

### New Capabilities

- `local-session-scheduling` 定义本地 Run 容量、等待生命周期和名额交接。

### Modified Capabilities

## Impact

涉及宿主装配、本地 Mesh、会话启动与恢复。首步范围为同一装配进程内的一个逻辑运行器。跨进程队列和跨运行器调度另行设计。
