# 本地持久产物规范

## ADDED Requirements

### Requirement: 同一宿主的持久产物装配和额度

启用本地持久绑定时，宿主 MUST 在同一台机器上用同一私有目录和存储身份重新装配。产物绑定 MUST 跨进程强制单块、单产物、正文总字节数和份数上限，预留和已保留内容共同计入，校验元数据也须有界。受理不满足存储能力时 MUST 在工具派发前拒绝。

#### Scenario: 两个进程竞争持久目录容量

- **WHEN** 两个进程使用同一绑定，且其中一个已占用产物预留或保留空间
- **THEN** 另一个进程只能使用剩余额度。容量不足时拒绝相应调用，已有产物和有效预留继续可用

#### Scenario: 重启后替换存储目录

- **WHEN** 新进程以相同路径打开一个具有不同存储身份的目录
- **THEN** 新目录不能验证原引用，依赖该绑定的可恢复 Run 在进一步派发前因绑定不匹配停止

### Requirement: 先持久封存再确认发布

产物绑定 MUST 在 `Complete` 返回前持久封存不可变正文和元数据，绑定所有者、原调用、版本、尺寸、摘要及到期时间。封存引用只能由受信的运行器确认。绑定 MUST 在可信原回执选中该引用后原子提交可见状态；同一确认重试 MUST 返回同一引用和额度计量。

#### Scenario: 分块写入或封存完成后退出

- **WHEN** 写入方在 `Complete` 前退出，或封存后尚无匹配的原回执便退出
- **THEN** 宿主读取不到这些产物。已封存正文只能由原调用的恢复流程核验

#### Scenario: 可见提交中断或重复

- **WHEN** 运行器已确认原回执，发布时退出或确认响应丢失，另一进程重新核对同一引用
- **THEN** 可以验证并接用已发布的版本，或从同一封存版本完成发布。一次确认最多产生一个可见版本，正文、尺寸和到期时间保持原值

### Requirement: 有界分页和独立的产物留存

读取 MUST 验证可信所有者、完整引用、发布状态和有效期。每页 MUST 校验所涉及的正文块并受页上限约束。产物到期时间在封存时固定，覆盖原 Run 的核对边界，查询、重启、接管与重试均不得延长期限。回收 MUST 保留有效引用和仍可完成的预留。

#### Scenario: 新进程按原引用分页读取

- **WHEN** 获授权的所有者在到期前按原引用读取，分别请求跨块页、末尾页以及从文件长度处开始的页
- **THEN** 每页返回已校验的原字节、下一偏移与 `EOF`。偏移等于尺寸时返回空页和 `EOF=true`，拼接内容与引用的尺寸和 SHA-256 一致

#### Scenario: 读取无法验证的引用或内容

- **WHEN** 主体、运行器、Run、引用字段、存储身份或偏移不匹配，产物尚未发布、缺失、到期，或所读正文块未通过校验
- **THEN** `ReadArtifact` 返回 `ErrArtifactUnavailable`，该页无正文。读取失败不改变已经持久化的工具结果或 Run 终态

#### Scenario: 清理过期记录时另一个进程仍在使用存储

- **WHEN** 一个进程回收已过期的发布记录或已无写入者的暂存记录，同时另一个进程持有有效预留或读取未过期产物
- **THEN** 只回收已满足条件的记录和正文，释放对应额度。正在写入的预留和未过期的已封存或已发布版本保留
