# 阶段 C 首步 · 本地会话历史

## Why

阶段 B 能恢复单次 Run。阶段 C 首步需要把 Run 已确认的消息增量写入会话历史，并保证一个会话等待工具时，另一个会话仍能启动、观察和提交。

## What Changes

- 为每个会话持久保存已提交历史和单调版本。启动时从该版本读取完整轮次的快照。
- 固定会话与 `RunID` 的归属，原子追加 `Wait` 的消息增量和去重回执。验证重复提交、版本冲突和进程退出后的接续。
- 同一会话最多受理一个待提交 Run。用两个会话验收独立派发、流式观察、取消和提交。

## Capabilities

### New Capabilities

- `session-history` 定义同宿主会话快照、Run 结果提交和会话间独立推进。

### Modified Capabilities

## Impact

首步覆盖本地 Go SDK 及会话存储，通过已有客户端执行和恢复 Run。会话级排队、TUI 和跨主机部署各自评审。
