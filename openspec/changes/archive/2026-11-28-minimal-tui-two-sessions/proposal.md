# 最小 TUI · 双会话

## Why

本地 SDK 已能保存两条独立会话，并在容量不足时按序等待。最小终端入口需要把各会话的排队、输出和取消呈现为可操作的状态。

## What Changes

- 打开两个本地会话，用键盘切换视图。每个会话保留自己的历史、输入草稿和实时输出。
- 增加可选的 SDK 受理进度通知。终端从调度器确认排队和取得名额，再从原 Run 读取流与终态。
- 用同一个按键取消当前会话的等待或 Run，并在取消与受理竞争时沿原 `RunID` 收尾。

## Capabilities

### New Capabilities

- `local-tui` 定义两个会话的终端操作、流展示和取消。

### Modified Capabilities

- `local-session-scheduling` 增加供宿主观察排队与授予名额的受理进度契约。

## Impact

首步覆盖一个本地终端进程及其 SDK 装配。验收由宿主注入两个会话、可控模型与慢工具。会话管理、跨进程界面恢复和终端框架选型留待后续评审。
