## Why

运行器可能失联但继续运行。接管同一个 Run 时，新旧进程都可能持有待提交的结果或在途工具请求，需要明确唯一本轮推进者以及旧写入在何处被拦下。

## What Changes

- 为显式开启接管的 Run 定义共享所有权、到期接管和单调递增的所有权代次。
- 在检查点提交、组件接单和工作区发布处核验所有权。新运行器等待旧写入被隔离，再继续原 Run。
- 区分旧运行器迟到的上报与原工具方的持久回执。核验通过的回执可由当前运行器结算一次。

## Impact

涉及运行器、共享检查点、Mesh 准入、原工具回执库和执行环境。首轮验收在同一宿主用两个存活的运行器进程和可控断连复现，不要求部署新的远程传输。
