## 3. 旧进程存活的端到端验收

- [x] 3.1 启动两个真实运行器进程，用共享裁决组件的可控时钟令旧租约到期。原工具在接管前向 `notes.txt` 写入 `saved:c1`，接管后才保存可查回执。测试期间保留旧进程存活并让它提交迟到结果，确认提交被拒。检查文件仅一行、原工具一次执行、当前运行器只结算一次，下一轮模型收到一份配对结果。
- [x] 3.2 在同一夹具中将旧工具阻塞在可见发布前，接管后释放阻塞。分别验证旧发布被拒且可信的未执行回执可回传，以及没有可信回执时以 `ToolOutcomeUnknown` 收尾。两种情况都检查工作区零新写入、原调用零重发和原预算未重置。
