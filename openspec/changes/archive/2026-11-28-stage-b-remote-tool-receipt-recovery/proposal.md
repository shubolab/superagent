## Why

远程工具可能已经保存文件，但连接在回执抵达运行器前断开。可恢复 Run 需要通过原工具方确认这一次调用的结果，从已提交的检查点继续，并控制找不到可信回执时的收尾。

## What Changes

- 接通 Mesh 的远程工具调用和只读回执查询，持久化足以重新找到原提供方和原调用的标识。
- 在可能已送达的连接故障后，从未结算的工具调用开始核对。可信回执只结算一次，完整工具批次提交后才进入下一轮。
- 对查不到可信回执的 Run 执行原截止、核对期限和取消规则。整个恢复过程保持原调用零重发。

## Impact

涉及运行器、Mesh 远程工具绑定、原提供方的回执记录和保留工作区。首轮验收使用本地运行器和可控模型、独立工具服务进程与真实回环连接，覆盖可重复的断连注入。
