# 阶段 A · 本地故障与并行隔离

## Why

正常闭环已能执行有界搜索。宿主还需确认回执丢失、取消和慢观察者不会引发重复操作或影响其他 Run。

## What Changes

- 区分启动调用失败与可能已受理；宿主可凭原 RunID 查询或重送相同请求。
- 用进程内故障替身验收工具副作用与回执分离、观察溢出以及两路 Run 隔离。
- 用可控时间复验 Run 截止、停止传播和回执等待上限。

## Capabilities

### Modified Capabilities

- `run-lifecycle` 增加丢失回执及并行故障的验收契约。

## Impact

SDK 启动错误、Mesh 交付证据及本地端到端验收。阶段 A 继续使用同一运行器实例内的运行状态。
