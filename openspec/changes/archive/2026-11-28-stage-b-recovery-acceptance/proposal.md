# 阶段 B · 恢复验收收口

## Why

本机重启、运行器接管、远程断连和写入证据重建已有单项验收。阶段 B 还需要验证这些故障叠加时，同一个 Run 能按原证据和已持久化位置续跑，或在原期限内安全收尾。

## What Changes

- 用两个运行器和独立工具服务的真实回环连接验证接管、回执重建和再次崩溃。分别核对单个工具结算、整批提交和终态。
- 覆盖证据不可用、工作区在查证后变化，以及跨进程读取大产物和结果过期。记录部署所用的保留能力和仍未验收的边界。

## Capabilities

### New Capabilities

### Modified Capabilities

- `run-recovery` 明确重建回执跨代次结算、批次中断后恢复、部署绑定的产物保留，以及恢复能力不足时的受理边界。

## Impact

以同一宿主的 Go SDK、Mesh、持久检查点和原工具服务为验收范围。使用现有恢复入口、回执和授权契约。跨主机部署、生产留存回收、可恢复压缩和事件重放单列在验收矩阵的后续范围。
