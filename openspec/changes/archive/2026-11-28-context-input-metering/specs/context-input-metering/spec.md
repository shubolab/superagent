# 模型上下文计量

## ADDED Requirements

### Requirement: 窗口与输入准入

启用模型计量的运行器 MUST 在每次正式派发前经 Mesh 核对可靠计量，用模型窗口减输出保留、独立输入限额及安全余量计算可用窗口，并同时执行 SDK 输入字节余额。

#### Scenario: 硬限额等值与越界
- **WHEN** 输入等于有效 token 或字节限额，或超过任一限额一单位
- **THEN** 等值请求可发。超限时原视图零派发，Run 返回对应预算终态

#### Scenario: 缺少可靠计量
- **WHEN** 配置要求计量，但绑定不提供有效窗口、计量或已校准的估算版本
- **THEN** 正式请求零派发，Run 以 context_measurement_unavailable 失败

### Requirement: 计量与发送一致

计量适配器 MUST 通过同一供应商编码路径计算计量和输入指纹，覆盖模型、版本、实际消息、工具声明、摘要与输出选项。运行器携带预期指纹，适配器在外部请求前核对。

#### Scenario: 工具声明改变
- **WHEN** 在计量后改变影响供应商输入的 schema
- **THEN** 适配器报 context_input_changed，供应商请求为零

### Requirement: 估算版本失效

模型输入使用已校准估算且供应商报告的实际输入比估算高出超过安全余量时，Mesh MUST 停用该模型绑定的该计量版本，后续同版本请求无法判定准入。

#### Scenario: 安全余量多一单位
- **WHEN** 实测输入比估算多 4001，安全余量为 4000
- **THEN** 后续使用该版本的 Run 报计量不可用，实际输入用量按供应商报告记录一次
