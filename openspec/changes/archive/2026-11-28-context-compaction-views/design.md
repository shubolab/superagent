# 上下文视图与原文回查设计

## Context

[压缩算法](../../../docs/specs/context-compaction.md) 与 [压缩接口](../../../docs/specs/context-compaction-contract.md) 规定触发计算、原文保护和降级顺序。

## Goals / Non-Goals

完成独立可选的本地运行器压缩及确定性验收。真实模型需满足设计中另外列出的实测门槛。

## Decisions

- 调用按原始消息起始索引定位完整块，索引在一次 Run 的追加记录中稳定。原文引用随机生成并绑定到本 Run，同一块引用复用。
- 策略按模型显式配置。压缩 Run 须选宿主登记且授权的原文回查工具。宿主固定项使用历史消息索引。
- 优先缩减旧工具正文，保留调用、回执状态及引用。摘要保留未覆盖的块，已有条目增量合并。失败恢复按缩减、已接受视图、原文排序。
- 摘要独占 Step，沿用模型客户端。输入、规范输出和请求次数各自结算，消息和观察仍以普通模型轮次为准。

## Risks / Trade-offs

结构化来源以其规范消息编码回查，纯文本来源以原始文本字节回查。页数据为字节片段，来源工具用 Base64 表达。
