# 本地读取容量

## ADDED Requirements

### Requirement: 读取能力和生效预算

本地读取环境 MUST 公布可强制的扫描字节、运行截止、并发和等待上限。运行器 MUST 将环境扫描上限与工具和 Run 上限取小。

#### Scenario: 环境上限更低
- **WHEN** Run 和工具的扫描额度大于环境上限
- **THEN** 按次授权和 Tool.Invoke 只获得环境允许的额度，实际读入保持在该额度内

#### Scenario: 能力不足
- **WHEN** 环境明确声明无法强制读取或期限上限
- **THEN** 运行器回报可识别的环境能力错误，工具派发为零

### Requirement: 活跃和排队读取均有上限

本地环境 MUST 在授予读取许可前申请共享容量。等待队列满时拒绝新调用，取消或到期时释放等待位置，撤销或释放授予后释放活跃位置。

#### Scenario: 三路 Run 争用
- **WHEN** 仅一个读取活跃位和一个等待位，甲占用、乙排队、丙随后申请
- **THEN** 丙没有读取授权或工具执行，回报 environment_busy。乙取消后等待位可复用，甲收尾后后续 Run 可以获得活跃位
