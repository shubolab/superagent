# TUI · 本地有界搜索契约

## ADDED Requirements

### Requirement: 命令显式开通本地搜索

`superagent` MUST 仅在传入有效的 `-workspace <目录>` 时为新 Run 装配 `search` 和同一个只读根目录。模型可请求获准目录内的相对普通文件。运行器 MUST 按 Run 持有正数、有限的工具尝试及扫描预算，按次授予读取额度，并通过原状态目录中的持久回执保存已知结果。工作区与状态目录 MUST 相互独立。

#### Scenario: 纯文本与显式工作区

- **WHEN** 用户分别省略 `-workspace` 或显式传入有效目录，从实际命令启动
- **THEN** 前者的模型请求只使用原纯文本能力。后者的模型请求只额外声明内建 `search`，一次调用接收工作区相对 `path` 和字面 `query`
- **AND** 历史继续归属原主体和会话，已有纯文本 Run 的恢复资格保持一致

#### Scenario: 无效目录与越界路径

- **WHEN** 启动时目录无效、不可用或与状态目录重叠，或已启动的模型请求越界路径或非普通文件
- **THEN** 无效配置在首个模型请求前返回可辨识错误。越界调用的实际文件读取为零，并在原会话显示拒绝或明确未执行

### Requirement: 展示搜索调用及配对结果

终端 MUST 按会话、`RunID` 和 `CallID` 关联搜索状态。只有派发事件可显示「搜索中」。完成事件提供观察状态，确认后的搜索结论取自完整配对消息中的有界结果。终端 MUST 对预览做长度和安全字符限制，且同一调用在本轮界面只保留一条状态或结论。

#### Scenario: 搜索命中并继续回答

- **WHEN** 模型先流式声明搜索，交付完整回复后派发，并收到已配对回执
- **THEN** 派发前未显示搜索进行中。派发后显示搜索，确认结果后显示扫描字节、返回的命中数及有界行号和预览
- **AND** 切到另一会话再切回可看到原搜索进度。可信终态替换同一调用的观察条目，重进后从已提交消息读回确认过的搜索结论

#### Scenario: 拒绝、失败与观察中断

- **WHEN** 搜索被拒绝、明确未执行、执行失败，或观察流在等待终态时关闭
- **THEN** 终端显示对应状态。拒绝和失败的条目按原调用归属，观察中断时仍等待可信终态，确认前不会用临时事件生成历史

### Requirement: 区分部分覆盖与 Run 预算停止

终端 MUST 区分已完成的搜索报告与 Run 停止。已知的部分搜索 MUST 显示「部分覆盖」、实际扫描字节及停止原因。只有已确认完整扫描且无匹配时才显示「完整 · 0 命中」。Run 因预算耗尽结束时，终端 MUST 单独显示 Run 停止及可确认的预算维度，并保留此前已提交的搜索结论。

#### Scenario: 完整与部分的零命中

- **WHEN** 小文件扫描到末尾仍无匹配，或大文件在扫描上限前无匹配
- **THEN** 分别显示「完整 · 0 命中」与「部分覆盖 · 扫描上限」，均显示实际扫描量。已知的部分报告可随配对结果交给下一轮模型

#### Scenario: 工具和 Run 分别触达上限

- **WHEN** 搜索达到单行、命中、预览或回执上限，或下一步因原 Run 额度不足无法派发
- **THEN** 搜索结果显示对应限额及可确认的有界内容。Run 预算停止另有终态，已提交的搜索结论保持可见

### Requirement: 重进核对原搜索回执

终端 MUST 在重进时只核对原会话的持久状态。未完成 Run 由当前会话按 Enter 后沿原 `RunID` 接续。运行器 MUST 在原核对窗口内用原调用身份和绑定查询可信回执，或从已结算检查点直接读回。终端 MUST 以可信终态及配对消息收尾，原工具重发次数为零。

#### Scenario: 回执先于结算持久化

- **WHEN** 原搜索已保存回执，在运行器结算前退出并启动第二个命令进程
- **THEN** 初次显示原 `RunID` 和「可继续」，未确认前查询、模型派发及工具派发均为零。按 Enter 后用原 `CallID` 查询并结算一次，下一轮模型只收到一份原结果
- **AND** 已结算分支从检查点接续，原查询和重复结算均为零。原搜索结论进入历史一次

#### Scenario: 核对期结束仍无可信回执

- **WHEN** 保有可信 Run 检查点，但原回执缺失、损坏或身份不符
- **THEN** 核对结束后显示「工具结果待核对」，以原调用关联的 `ToolOutcomeUnknown` 收尾。未确认批次不会生成结果条目或进入历史，新模型与原工具重发次数均为零
- **AND** 活跃原进程占用或当前装配无法核对原工作区时沿现有占用或待核对路径，保留原 `RunID` 和既有历史
