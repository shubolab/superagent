# TUI · 命令接入本地有界搜索

## Why

实际的 `superagent` 命令目前只装配模型。宿主已经能搜索获准的本地文件，终端还需要把这条链路接到命令入口，并让用户看到搜索覆盖、限额和重进后的原回执结论。

## What Changes

- 以 `-workspace <目录>` 显式开启 `search`。两条会话各自的 Run 使用同一只读工作区，调用权限、预算和回执仍按原 Run 归属。
- 在当前会话展示搜索发出、结束和配对结果，区分完整零命中、部分覆盖、拒绝、Run 预算停止和原回执待核对。
- 重进沿用原 `RunID` 和阶段 B 查询。已结算结果从检查点读回，未结算调用由原提供方核对回执。
- 验收覆盖实际命令、真实文件、独立进程和伪终端。模型使用回环 Messages SSE 夹具控制回复和记录请求。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `local-tui` 增加命令工作区装配、搜索展示和原回执恢复行为。

## Impact

涉及 `cmd/superagent` 与 `internal/tui`。复用 SDK 的本地只读环境、内建搜索、持久回执及会话恢复。递归搜索、正则、通用命令、远程执行及工作区写入留给单独变更。
