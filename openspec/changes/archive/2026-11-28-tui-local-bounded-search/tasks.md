## 验收用例

使用 `go build ./cmd/superagent` 构建命令，用 PTY 启动，指向回环 Anthropic Messages SSE 夹具。使用真实工作区文件及会话、检查点和回执目录。正常用例直接跑构建产物。故障用例可用测试构建在同一命令装配上设同步点，真实退出并用新进程打开同一状态。记录故障注入位置和生产命令的实跑结果。

| 用例 | 操作 | 通过条件 |
| --- | --- | --- |
| 1. 命令和工作区 | 分别用纯文本、有效目录、无效目录和重叠路径启动。启用后提交绝对路径、`../`、越界链接和非普通文件的模型调用 | 只有启用分支声明 `search`。无效配置发请求前退出。越界分支读量为 0，原会话显示拒绝或明确未执行。原纯文本历史可读 |
| 2. 两轮搜索与显示 | 甲搜索 13 字节的 `docs/health.txt`，内容为 `status=ready\n`。暂缓发送模型完成帧，再放行。搜索时来回切换甲乙，另跑一次观察中断 | 调用增量期间派发为 0，完整回复后显示搜索和完成。模型请求 2 次，工具执行 1 次，下一轮含配对结果。甲显示 13 字节和第 1 行，历史 v1、结果一份；乙无甲的工具条目 |
| 3. 搜索内限额 | 分别使用小文件零命中、远大于 1 MiB 的短行零命中文件、超长单行、长预览、密集命中与编码回执边界 | 只有完整分支显示完整零命中。其余显示部分覆盖或明确限额错误及匹配原因。累计读取 ≤ 1 MiB，单回执 ≤ 16 KiB，界面最多显示 3 条预览。放大源文件记录峰值 RSS，读量仍受同一上限约束 |
| 4. Run 超限与两会话 | 甲先提交一份用尽扫描余额的搜索结果，模型下一轮再发起搜索。乙在可用名额内独立输出 | 第二次搜索实际执行 0 次。甲显示 Run 扫描预算停止，首份部分结果仍可见并只进历史一次。乙的输出、历史和额度独立 |
| 5. 有回执时重进 | 甲的原回执持久化、结算前结束进程，随后修改原文件内容，保留工作区身份。重进，先操作乙，再在甲按 Enter | Enter 前查询与新增派发为 0。按键后以原 RunID、CallID 查询并照原账本结算一次。Step 2 得到原内容，原搜索执行总数 1。甲历史 v0 → v1，旧工具事件无重放 |
| 6. 已结算与已终止重进 | 在完整批次和结算持久后、下一轮意图保存前退出。另跑可信终态已保存、历史未发布的分支 | 前者接到原下一步，工具执行累计 1，新增查询、执行与结算均为 0。后者只补历史，新增模型和工具派发均为 0。再次重进都读回同一结果，历史 v1 |
| 7. 查不到可信回执 | 让原调用处于未结算状态，分别停在回执缺失、记录损坏或 CallID/指纹不符的分支，再用原装配恢复。附测换根及旧进程占用 | 查询沿用原期限，窗口结束按原调用显示 `ToolOutcomeUnknown`。未确认批次入历史为 0，原调用重发和后续模型派发为 0。换根或仍占用时保留原 Run，乙仍可操作 |
