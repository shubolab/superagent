# 本地工具产物设计

## Context

[大输出生命周期](../../../docs/specs/tool-call-lifecycle.md#大输出与结果大小) 与 [存储保留](../../../docs/specs/execution-environment.md#工作区和产物保留) 将小回执、原始输出和存储拆开。

## Goals / Non-Goals

实现阶段 A 的本地存储、按次写入、有界回执和归属校验。阶段 B 的重启索引与产物迁移单独评审。

## Decisions

- 宿主为 Mesh 登记可选产物提供方。工具声明产物需求，宿主为该工具授予写入权。
- 每次工具调用最多创建一个本地产物，写入块最多 64 KiB。提供方在派发前按单件、总容量和 Run 余量预留可用字节。
- 工具完成写入先得到暂存引用。正常回执携带完全匹配的引用后发布。其余暂存数据清理，已使用量仍入账。
- 产物位于宿主配置的独立私有目录。文件名由提供方生成，引用不含路径。读取校验所有者、版本、哈希、期限并返回有界页。

## Risks / Trade-offs

本地元数据由当前装配持有。宿主关闭时释放该装配的产物目录。
