# TUI · 本地重进恢复

## Why

现有双会话 TUI 能持续观察当前进程的 Run。终端退出后，用户需要重新看到各自已保存的对话，并分辨原 Run 可继续、只待保存，还是从未受理。

## What Changes

- 以原会话身份读回各自已提交的历史。启动时核对每条会话的待处理记录，界面可以独立切换。
- 已封存或可信终态按原 `RunID` 补存。已受理且未结束的 Run 由用户显式继续，使用原检查点与调度门禁。
- 主动退出时撤回尚在等待的启动或恢复请求。新进程从空队列启动，授予与退出相遇时按持久受理证据区分结果。

## Capabilities

### New Capabilities

### Modified Capabilities

- `local-tui` 定义主动退出、两条会话重进以及原 Run 的交互。
- `session-history` 增加只读恢复判定及按原记录受限收尾的契约。

## Impact

同一宿主与同一套本地存储，复用阶段 B 检查点、会话版本和阶段 C 调度。下次启动重新读取持久状态。持久等待队列、流事件重放与跨主机入口留在后续范围。
