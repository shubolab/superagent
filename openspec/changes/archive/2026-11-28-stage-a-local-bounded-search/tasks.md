# 阶段 A · 本地有界搜索任务

[设计与固定数据](design.md) · [搜索验收](specs/bounded-file-search/spec.md) · [Run 验收](specs/run-lifecycle/spec.md)

## 1. 共享契约与本地路由

- [x] 1.1 补齐工具登记、Run 环境要求、按次授权引用、模型工具调用、`Tool.Invoke` 回执和 SDK 事件类型。用外部包编译测试验证宿主能通过根包登记工具，回归原纯文本 DTO 和生命周期用例。
- [x] 1.2 为现有 Mesh 添加本地工具与环境路由，保留可信主体、调用绑定、标识及截止时间。用替身核对 `Invoke` 和环境操作各只路由一次，绑定缺失或身份不匹配时请求未交付。

## 2. 只读环境与按次授权

- [x] 2.1 在宿主登记的工作区建立 Run 句柄及按次权限，绑定 Run、Call、工具、主体、工作区、路径、额度和期限。验证有效许可可用，过期、撤销、跨主体和跨调用复用的实际读取次数为零。
- [x] 2.2 用许可根句柄开启有界文件读取并支持关闭和撤销。验收授权目录内的普通文件、目录外路径和越界链接、特殊文件拒绝，以及取消后句柄关闭和独立释放。

## 3. 有界搜索

- [x] 3.1 接通单文件字面搜索，实施分块扫描、单行、命中、预览和完整回执上限。验证 13 字节文件的命中、完整与部分零命中的区别、超长单行和命中过密，核对实际读取、缓冲和回执大小。

## 4. 推进、结算和收尾

- [x] 4.1 把纯文本推进扩展为多轮模型与串行工具批次，保留显式完整回复门槛。测试增量、提前 EOF、重复或缺失的 `CallID`、非法参数结构均产生零派发，纯文本回归继续通过。
- [x] 4.2 接通 Run 工具授权、按次环境授权、派发和回执分类。核对未授权绑定在受理时拒绝，派发前拒绝为 `rejected`，派发后确认未执行为 `failed`，并验证二者实际读取均为零、错误结果按原 `CallID` 回传。
- [x] 4.3 实现批次配对、预算逐步扣减和提交。验收报出的 13 字节实际用量、两轮规范输出与完整回执结算、拒绝计数、最小回执预留失败时的零执行，以及同轮两个调用依序提交。下一轮预算耗尽时核对已提交消息完整返回。
- [x] 4.4 将停止裁决延伸到已派发工具。验证派发前取消为零执行、已知结局按取消或超时收尾、无可信结局时提交 `ToolOutcomeUnknown`，并核对无后续派发、当轮未提交与清理状态独立。

## 5. 公开入口验收

- [x] 5.1 从 `NewMesh → NewClient → Start` 运行固定用例，核对两次模型请求、一次工具执行、13 字节读数、配对结果、四条增量消息、唯一终态和观察 EOF。运行 `go test ./...` 与 `go test -race ./...`，同时验证第一步的纯文本、观察和取消场景。
