# 上下文压缩对照设计

## Context

[上下文压缩验收](../../../docs/specs/context-compaction.md#验收) 要求比较三种历史策略，并计入摘要成本。

## Goals / Non-Goals

提供固定任务、可重复指标和真实运行入口。真实数据和启用结论来自配置模型的实测。

## Decisions

- 用固定文件读取验证一次实际工具执行。任务覆盖早期助手证据、原始用户限制和后续更正。
- 完整历史保留全部输入；近期策略保留所有用户原文和最后若干完整块；压缩策略由真实运行器裁决。
- 使用 Wait 的用量和压缩诊断计算数据，按显式输入和输出单价估算成本。每项结果记录为 JSON。

## Risks / Trade-offs

外部 API 只有在显式选择真实评估时请求。真实模式使用宿主可执行的已校准本地计量器。
