# 上下文压缩长任务对照

## Why

契约用例可以复验正确性。启用真实模型前，需要同一批长任务比较原历史、近期窗口和自适应压缩的收益与退化。

## What Changes

- 加入固定长历史、工具读取与用户更正任务，用相同模型配置对照三种历史策略。
- 按任务记录完成、原文约束、工具回放、窗口错误、总用量、成本估算及耗时。
- 允许本地模型复验对照方法。真实运行需显式启用并提供模型、凭据和已校准的本地计量。

## Capabilities

### New Capabilities

- `context-compaction-evaluation` 定义长任务对照验收和可重复的指标。

## Impact

增加测试入口和运行说明。常规测试不依赖供应商连接。
