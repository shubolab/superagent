# 可回查的上下文压缩视图

## Why

计量已能在派发前判定模型窗口。长 Run 还需要在保留用户约束及工具配对的前提下缩减模型输入，并在摘要失败时回退。

## What Changes

- 按完整消息块保护用户原文、宿主固定项及最近内容。
- 优先削减旧工具正文，其次为旧块生成带来源的摘要。持续基于原始消息和已接受摘要构建各轮视图。
- 保留有界的原文回查路径、独立摘要预算与按原版本排序的回退机制。

## Capabilities

### New Capabilities

- `context-compaction-views` 定义可选的上下文视图、摘要与来源读取。

## Impact

运行器新增可选压缩策略和只读来源路由。用确定性模型验收，真实模型的校准和长任务对照依照原设计门槛执行。
