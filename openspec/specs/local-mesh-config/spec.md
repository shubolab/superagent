# local-mesh-config Specification

## Purpose

定义 Go 宿主如何用版本化 YAML 连接本地模型、工具和环境，并校验角色引用与运行器可使用的组件范围。

## Requirements

### Requirement: 版本化本地绑定

SDK MUST 将版本 1 YAML 的模型、工具、环境逻辑引用解析为同类的宿主本地实现，并为每个运行器应用宿主策略与声明的可见范围。

#### Scenario: 与 Go 装配行为一致
- **WHEN** 文件与直接 Go 配置指定同一模型、工具、环境及宿主策略
- **THEN** 使用相同 NewMesh 和 SDK 入口可得到相同本地调用、授权和终态

#### Scenario: 不支持的配置
- **WHEN** 版本不支持、含未知字段、重复引用、声明的组件不存在或类型不匹配，或策略超出可见范围
- **THEN** 构造阶段报可识别的配置错误，尚未启动 Run

#### Scenario: 默认环境补全
- **WHEN** Run 明确请求工作区，未填写环境引用，且运行器设有默认环境
- **THEN** 运行器以默认环境解析，仍核对主体、该工具与工作区授权
