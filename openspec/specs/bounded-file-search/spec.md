# bounded-file-search Specification

## Purpose

为 Go 宿主提供单文件、只读的有界搜索能力。运行器以按次授权限制工具访问，执行环境核验实际文件，工具返回可计量的扫描结果和覆盖状态。

## Requirements

### Requirement: 按次授权的文件读取

本地环境 MUST 根据宿主预先绑定的工作区和许可目录签发只读授权，并在打开文件时核对主体、Run、调用、工具、范围、额度及期限。实际读取对象须位于获准目录内。

#### Scenario: 本次调用读取获准文件
- **WHEN** 工具持有绑定原主体、`RunID`、`CallID`、`ToolRef` 和工作区的有效授权，请求读取目录内的普通文件
- **THEN** 环境在授权额度和期限内提供有界读取

#### Scenario: 授权过期或被复用
- **WHEN** 授权已过期、已撤销、所属调用已结束，或被其他主体、Run、调用、工具或工作区复用
- **THEN** 环境拒绝请求，实际文件读取次数为零

#### Scenario: 路径或实际对象越界
- **WHEN** 请求绝对路径、尝试越过许可目录、通过链接指向目录外，或目标为目录或特殊文件
- **THEN** 拒绝读取。对于能确认未开始业务操作的已派发请求，工具回报 `not_executed`

### Requirement: 单文件搜索执行资源上限

搜索工具 MUST 对单个普通文件做区分大小写的单行字面匹配，分块读取并限制查询长度、扫描字节、单行缓冲、命中数、单条预览、编码回执和截止时间。

#### Scenario: 匹配完整的小文件
- **WHEN** 授权和预算允许搜索 13 字节的 `docs/health.txt`，文件内容为 `status=ready\n`，匹配词为 `status`
- **THEN** 返回 `status=ready` 这一条命中，实际扫描量为 13 字节，覆盖状态为完整

#### Scenario: 大文件一直无命中
- **WHEN** 短行持续产生且没有命中，读入达到累计扫描上限时仍无法确认文件末尾
- **THEN** 停止扫描，实际读取量在授予上限内，结果带扫描量、部分覆盖和限额原因

#### Scenario: 超长单行或命中过密
- **WHEN** 单行超过缓冲上限，或继续收集命中将超过命中、预览或回执上限
- **THEN** 只返回已经确认且能容纳的有界结果，标记部分覆盖及停止原因，整条回执在结果额度内

#### Scenario: 取消已打开的读取
- **WHEN** 授权撤销或截止生效，搜索正在读取文件
- **THEN** 停止后续读取并关闭本次读取句柄，授权无法继续使用，清理结果可独立核对

### Requirement: 搜索覆盖与可结算回执

搜索工具 MUST 在回执中包含可关联的调用标识、扫描量和覆盖状态。有界的部分结果可作为已知结果回传，完整零命中须以已确认的扫描覆盖为依据。

#### Scenario: 区分完整零命中和部分零命中
- **WHEN** 两次搜索均返回空命中，其中一次确认扫描到末尾，另一次先遇到扫描上限
- **THEN** 前者报告完整零命中，后者报告部分覆盖和已扫描字节数

#### Scenario: 受限结果可入账
- **WHEN** 工具按限额停止并返回配对的已知部分结果
- **THEN** 运行器按可核对的扫描字节和完整回执大小结算，模型收到限长结果及覆盖原因
