# local-tool-artifacts Specification

## Purpose

定义本地工具产物的授权、分块写入、独立预算、可信引用及有期限的读取，明确宿主如何获取 Run 输出的产物。

## Requirements

### Requirement: 受管的原始输出

运行器和产物提供方 MUST 将原始输出与小回执分别限制并扣减。只有显式获准的调用可以流式写入。

#### Scenario: 多次工具写入和独立回执
- **WHEN** 获授权工具以有界块写出并确认产物，随后同一 Run 再调用工具
- **THEN** 回执只传有界摘要与产物引用。下一调用仅获得 Run 未消耗的原始输出额度

#### Scenario: 超限、取消及中断
- **WHEN** 原始输出或单块超过上限，或完整产物未能随可信回执确认
- **THEN** 部分内容清理，模型得不到完整产物引用。实际已写字节扣除，缺少可信用量时保守扣授权额度

### Requirement: 完整引用和所有者读取

产物提供方 MUST 在接受完整工具回执后发布经校验的引用。引用绑定运行器、主体、Run、大小、内容哈希、版本和有效期。

#### Scenario: 读取保留产物
- **WHEN** 所有者在有效期内按页读取
- **THEN** 页大小受配置约束，读取原始字节。跨 Run、跨主体、篡改引用或过期时均不可查
