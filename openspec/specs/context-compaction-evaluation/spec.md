# context-compaction-evaluation Specification

## Purpose

规定如何比较同一批长任务的三种历史策略，记录每种策略的任务正确性、资源、时延和摘要用量，并据此判断压缩收益。

## Requirements

### Requirement: 固定输入的三策略对照

验收工具 MUST 以相同模型、任务、用户原文、工具与工作区数据比较完整历史、近期窗口和自适应压缩。

#### Scenario: 早期证据与后续更正
- **WHEN** 长任务包含早期确认结果、原始用户约束、用户更正和一次受授权搜索
- **THEN** 每种策略在新的 Run 和工作区上执行。结果分别记录能否返回正确证据、约束是否保留及工具执行次数

### Requirement: 记录包含摘要的成本

验收工具 MUST 记录每次 Run 的输入和输出用量、窗口停止、用量成本、延时及摘要消耗。

#### Scenario: 本地对照和显式真实对照
- **WHEN** 使用确定性模型，或显式选择真实模型并提供已验证的计量配置
- **THEN** 产出相同指标格式。普通测试可重复执行，不发供应商请求
