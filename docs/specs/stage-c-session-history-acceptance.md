# 阶段 C · 本地会话历史验收

2026-11-28，macOS arm64，Go 1.24.3。变更为 `stage-c-local-session-history`。使用 SDK 本地 Mesh、真实会话与阶段 B 检查点目录、可控模型。重启用例启动独立测试进程，并在指定持久化边界强制终止原进程。

| 用例 | 观测 |
| --- | --- |
| C1 · 重启续聊 | 两个进程共发出 2 次模型请求。后继进程从 v1 继续，首个请求依次包含上轮输入、答复和本轮输入，最后提交到 v2 |
| C2 · 受理恢复 | 预约后退出，续接只派发 1 次。原工具回执已落盘时退出，新进程查询原回执 1 次，原工具执行总数仍为 1，模型从第 2 轮继续。请求摘要错配、过期、缺失或更换存储均保留原预约，新增派发为 0 |
| C3 · 原子去重 | 封存后强制退出读到 v0，发布后强制退出读到 v1。每个分支的 2 个并发进程和后续迟到重试均返回同一 v1 回执，原 Run 消息只追加一次。阶段 B 终态已过期时仍可由封存记录发布或读取已发布回执 |
| C4 · 会话隔离 | 甲阻塞在第二次工具调用时乙流式完成并提交到 v1。乙下一轮收到首段后取消甲，乙继续收到后续增量并提交到 v2。甲只提交已确认的首个工具轮次，版本为 v1。模型共派发 4 次，甲工具调用 2 次，忙时请求派发 0 次 |
| C5 · 提交保护 | 跨会话、跨主体、终态内容冲突、过时版本及文件系统写入失败均返回可识别错误。故障下旧历史保持 v1，原回执相同。恢复存储后由独立进程提交到 v2，重复读取回执一致 |

取消请求、观察断开和等待超时发生时，已提交版本保持原样。取消、失败和 `ToolOutcomeUnknown` 的终态提交只纳入本次输入和此前完整的工具轮次。 [跨进程验收](../../sdk/session_process_test.go) · [双会话与终态验收](../../sdk/session_concurrency_test.go)

## 复验

C1–C5、全量普通回归、全量 race 检查、`go vet ./...` 与 OpenSpec 严格校验均通过。普通及 race 回归使用本地测试，Anthropic 实连冒烟和评估开关为 0。

```sh
go test -count=1 ./...
GORACE=atexit_sleep_ms=0 go test -race -count=1 ./...
openspec validate --all --strict
```
