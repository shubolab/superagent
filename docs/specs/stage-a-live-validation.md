# 阶段 A · 真实网关验收

验收日期为 2026-11-27。CC Switch 当前 Claude 条目为「百智-国内模型」，通过 Bearer 连接 Anthropic 兼容网关，实际模型为 `glm-5.3-flash`。适配器启用有界思考块丢弃。 [模型适配器](model-adapter.md)

## SDK 冒烟

`TestAnthropicLiveSearch` 通过。两轮模型请求完成，搜索仅执行一次，实际读取 13 字节。模型返回配对结果和最终答复。供应商报告 478 个输入 token、87 个输出 token，总耗时 5.12 秒。

## 计量校准

- 网关的 `count_tokens` 返回 HTTP 404。本地采用公开 GLM tokenizer 和 chat template，以 Anthropic 请求中的实际指令、消息及工具编码为输入。将声明与配对回执映射成对应工具角色。 [固定模型资产版本](https://huggingface.co/zai-org/GLM-5.3-Flash/tree/46a050bec13002ad29ee795c16e61cf4fa3c4a9c)
- 六个校准请求覆盖普通文本、工具声明、工具回执、摘要及长输入。网关报告的输入为 31 至 4,549 token，本地计量的最大绝对偏差为 2 token。
- 测试策略提供 5,912 token 宿主窗口、1,024 token 输出保留和 64 token 安全余量。硬输入限额为 4,824 token，软触发点为 4,341 token。实测结论适用于这条网关绑定和本次配置。

## 长任务对照

`TestAnthropicLiveCompactionComparison` 最终通过，耗时约 149 秒。固定任务使用每块 20 行的历史。输出 token 包含供应商报告的思考用量。成本使用本机 CC Switch 登记的单价估算。

| 任务 | 策略 | 答对 | 输入 token | 输出 token | 秒 | 估算 USD |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| 早期证据 | 完整历史 | 是 | 9,110 | 168 | 50.6 | 0.001451 |
| 早期证据 | 近期窗口 | 否 | 2,818 | 425 | 13.3 | 0.000635 |
| 早期证据 | 自动压缩 | 是 | 9,719 | 1,009 | 37.0 | 0.001962 |
| 用户更正 | 完整历史 | 是 | 9,134 | 160 | 7.6 | 0.001450 |
| 用户更正 | 近期窗口 | 是 | 2,148 | 120 | 5.0 | 0.000382 |
| 用户更正 | 自动压缩 | 是 | 9,748 | 950 | 35.6 | 0.001937 |

- 两个自动压缩 Run 都执行了摘要并选中压缩视图。六个 Run 都保留用户原文，每次只读取 13 字节，工具重放为零。最大输入低估为 2 token。
- 使用 512 token 输出保留的先行对照发生了摘要回退。最终验收将输出保留调至 1,024 token，并保持同一硬输入限额。
- 这组样本中，自动压缩保留了近期窗口遗漏的早期证据。计入摘要后，两题汇总的用量成本高于完整历史。 [长任务评估入口](context-compaction.md#长任务对照入口)
